# SnowRider3bSetPb
Allows for one to set their personal best in snowrider3d (tested site: https://www.snowrider.com/game-classic/)

## Usage

To use, copy-paste [main.js](this file) (ctrl-a, ctrl-c) then go into 'inspect' and ctrl-v. Afterwards run:

~~~JS
let score = 67; // Change value here!
await setPb(score);
~~~

And reload the page. Afterwards, your high score should be changed.
